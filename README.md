# SOC310 Community Advocacy Campaign Website

This is a simple static GitHub Pages website for a SOC310 Racism and Ethnic Relations community advocacy campaign titled **“Language Barriers and Healthcare Inequality.”**

The site uses only:

- `index.html`
- `styles.css`
- `assets/`
- `README.md`

There are no frameworks, build tools, or npm dependencies.

## How to Deploy on GitHub Pages

1. Push `index.html`, `styles.css`, `assets/`, and `README.md` to a GitHub repository.
2. Go to the repository’s **Settings** tab.
3. Open **Pages** in the left sidebar.
4. Under **Build and deployment**, select the `main` branch and the root folder.
5. Click **Save**.
6. Open the published GitHub Pages link after it finishes deploying.
